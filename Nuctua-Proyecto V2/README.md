# 👟 Nuctua V2 – Plataforma E-Commerce de Calzado Exclusivo

Prototipo interactivo de alta fidelidad diseñado en **Figma** para la aplicación e-commerce de calzado exclusivo **Nuctua (Versión 2.0)**. Esta versión amplía integralmente el ecosistema del proyecto con **22 vistas interconectadas** que cubren tanto la experiencia completa de compra del cliente (tienda, búsqueda, colecciones, carrito, checkout y perfil) como el portal operativo de administración (**Backoffice**).

## 📌 Descripción del Proyecto (Evolución V2)
**Nuctua V2** evoluciona desde el flujo base de cliente hacia una arquitectura e-commerce dual bajo una identidad visual **neo-brutalista editorial** (fondo crema `#FDF5EC`, alto contraste `#141414` y acentos naranja `#EB5823`):

1. **Autenticación y Acceso Multi-Rol (3 vistas):** Inicio de sesión para clientes, registro de nuevas cuentas y portal exclusivo de acceso para administradores.
2. **Catálogo, Búsqueda y Colecciones (6 vistas):** Página de inicio (*"Pisa con Actitud"*), buscador global con historial reciente y filtros multicriterio (categoría, talla, color, precio), además de colecciones dedicadas para **Novedades**, **Hombre**, **Mujer** y **Calle**.
3. **Flujo de Compra y Checkout (2 vistas):** Carrito de compras con ajuste de tallas/cantidades y aplicación de cupones, conectado al checkout (*"Casi Tuyos"*) con datos de envío y métodos de pago (Tarjeta, PSE, Nequi y Contra entrega).
4. **Cuenta de Usuario y Fidelización (3 vistas):** Perfil editable con múltiples direcciones y preferencias de talla/estilo, historial cronológico de pedidos con recompra rápida y lista de deseos (**Favoritos**).
5. **Panel Administrativo / Backoffice (8 vistas):** Gestión centralizada de inventario con alertas de stock y edición por talla, administración de pedidos y estados de despacho, catálogo CRUD de productos con vista previa en vivo, directorio CRM de clientes, buscador global administrativo y perfil de seguridad del administrador.
